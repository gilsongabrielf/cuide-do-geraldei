# Cuide do Geraldei 🐾

Pasta estática pronta para abrir no navegador ou hospedar em qualquer serviço estático (Vercel, GitHub Pages, Cloudflare Pages, Netlify).

## Abrir localmente

Na raiz do repositório:

```bash
node scripts/serve-geraldei.mjs
```

Ou dentro desta pasta:

```bash
python -m http.server 8080
```

## Sprites oficiais utilizados (`assets/sprites/`)

- `WhatsApp Image 2026-11-18 at 15.58.00 (4).jpeg` — carinhoso/apaixonado (beijinho e coração)
- `WhatsApp Image 2026-11-18 at 15.58.00 (2).jpeg` — brincalhão/animado (frame 1)
- `WhatsApp Image 2026-11-18 at 15.58.00 (3).jpeg` — brincalhão/animado (frame 2)
- `geraldei-emburrado.jpeg` / `geraldei-carente.jpeg` / `geraldei-serio.jpeg` — postura séria/emburrada ou carente

Os recortes transparentes em `assets/sprites/cutouts/` removem apenas o fundo cinza externo preservando intactas todas as feições e o contorno de figurinha.
